# Project Overview — Campus Canteen Ordering System

## Problem

The college canteen accepts orders manually. Students queue, ask which items
are available, work out their own totals, and ask staff about order status.

## Goal

Help students select available food items and help canteen staff process orders.

## Initial focus

- Menu viewing
- Creating an order (items and quantities)
- Calculating the total
- Submitting an order
- Checking order status

Real payment processing is outside the first version.
