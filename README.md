# Campus Canteen Ordering System

A simple system that lets students view the college canteen menu, select items
and quantities, see a correct order total, submit an order, and check its
status. Canteen staff review incoming orders and update their status.

This repository is used for Software Engineering labs (requirements gathering,
agile planning, change control, and review).

> A student can see available menu items, select one or more items with valid
> quantities, and see a correctly calculated total before submitting an order.
